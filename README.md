Тип приложения: REST API на Flask для учёта личных расходов.

Аутентификация: реализована через JWT (регистрация, вход, защищённые маршруты).

Пользователи: каждый пользователь имеет уникальные username и email; пароли хранятся в хешированном виде.
Расходы: привязаны к пользователю, содержат сумму (expense), категорию и дату создания.
Операции с расходами:
добавление,
редактирование,
удаление,
получение по периоду (неделя, месяц, 3 месяца, всё время, кастомный диапазон),
фильтрация по категории,
расчёт общей суммы и доли категории в процентах.

Безопасность:
каждый пользователь работает только со своими данными,
все изменяющие операции требуют валидного JWT-токена.

Архитектура:
использует Flask + Flask-SQLAlchemy (ORM),
данные хранятся в PostgreSQL,
нет фронтенда — только API для клиентов (мобильных приложений, веб-интерфейсов и т.п.).
Приложение предназначено для персонального или многопользовательского учёта расхо
